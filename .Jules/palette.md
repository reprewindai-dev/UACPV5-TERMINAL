## 2024-03-08 - Disabling input and run button during typing state
**Learning:** In interactive terminals or chat interfaces, if the user submits a command, there is a `isTyping` state. During this state, the user might try to interact with the input or the submit button which could result in unintended behaviors or confusion. Disabling them and providing visual feedback (like opacity reduction or changing cursor) improves the UX significantly.
**Action:** When `isTyping` is true, explicitly disable the run button and the input field so users know they need to wait. Apply utility classes to convey the disabled state.
